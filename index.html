01能解决的问题

下面这些我这一年内都实际处理过，不是猜测。

  • node_modules 只装了一半——显示安装成功，启动报 Cannot find module，目录里缺 package.json
  • 插件装了但界面不显示——依赖有、配置有、日志干净，就是没按钮（多半是 peer 版本上限被静默禁用）
  • 双击图标一闪就没——退出码 0、零报错，通常是环境变量把 Electron 当 Node 跑了
  • GitHub 拉取只有 2KB/s——Release 被限速，需要分段并行下载并校验哈希
  • 命令行解析不到 github 域名——DNS 被污染，浏览器正常、命令行全挂
  • 授权登录拿不到验证码——设备码流程在后台进程里不打印提示
  • 脚本一跑就报路径不存在——PowerShell 5.1 用 ANSI 读文件，中文路径变乱码
  • 服务起来了但功能是坏的——健康检查通过不代表业务跑通，需要看产出物

02怎么进行

  1. 先说现象把报错原文贴过来，说明系统和工具版本。我判断能不能远程解决。
  2. 约时间远程确认后约时间，你发起远程，我操作。需要授权的步骤（登录、输验证码）你自己点，我不碰你的密码。
