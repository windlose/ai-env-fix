## 二、小红书

### 标题

```
装了三天没跑起来，我总结出 Windows 装 AI 工具的 8 个坑
```

### 正文

```
不是教程，是踩坑记录。

这周在 Windows 上给一个 AI 编程工具配环境，八个坑，每个半小时以上。

① node_modules 只装了一半
显示安装成功，但 package.json 没了。因为软件开着，锁住了文件，pnpm 撞 EPERM，删了一半就停了。

② 插件装了不显示
依赖有、配置有、日志干净，界面就是没有。根因是插件的 peer 版本上限写死了 rc.2，你跑的是 rc.3，宿主静默禁用。

③ 双击一闪就没
退出码 0，没有任何报错。环境里有 ELECTRON_RUN_AS_NODE=1，Electron 把自己当 Node 跑了。

④ GitHub 下载 2KB/s
不是被墙，是限速。12 段并行 Range 才拉得下来。

⑤ raw.githubusercontent.com 解析到 0.0.0.0
DNS 污染。浏览器走 DoH 没事，命令行全挂。

⑥ 设备码授权拿不到码
stdout 重定向之后 CLI 以为没人在看，直接跳过提示。

⑦ 脚本里有中文路径就崩
PS 5.1 按 ANSI 读 .ps1。存 UTF-8 也是乱码，得带 BOM。

⑧ 服务起来了，功能一直是坏的
健康检查 200，端口在监听，实际一条都没跑通。

这八个有个共同点：都不报错。
Windows 的失败大多是静默的，所以排查第一原则不是看报错，是验证产出物。

——
完整版写在掘金，搜「Windows 上装 AI 开发环境，我踩过的 8 个坑」

卡住了可以问我，远程也能看。
```
